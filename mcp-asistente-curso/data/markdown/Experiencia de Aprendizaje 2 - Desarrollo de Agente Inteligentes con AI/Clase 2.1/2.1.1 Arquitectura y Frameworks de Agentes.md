### **¿Qué es un Agente Inteligente?** 

##### **Diferencias Clave:** 

Un agente de IA trasciende las limitaciones de un LLM tradicional. Mientras que un LLM funciona como una **entrada → salida** simple, un agente es un sistema autónomo que implementa un ciclo continuo de **percepción → razonamiento → decisión → acción** . 

**- LLM: Responde una vez con información estática de entrenamiento.** 

**- Agente: Mantiene conversaciones, usa herramientas externas, planifica y ejecuta tareas complejas.**

#### **Arquitecturas y Patrones de Implementación RA2/IL2.1/1-agent-fundamentals.ipynb** 

Implementación desde cero usando el patrón ReAct (Reason + Act). El LLM escribe intenciones en texto estructurado: **`"Action: {tool: 'search', query: 'Elon Musk'}"`** Parsing manual con expresiones regulares para extraer acciones. Limitaciones: Frágil, propenso a errores de formato, difícil de escalar. 

**Arquitecturas y Patrones de Implementación RA2/IL2.1/2-agent-function-calling.ipynb Function Calling Nativo:** OpenAI proporciona mecanismo estructurado para llamar funciones. El LLM devuelve JSON bien formado en lugar de texto a parsear. Definición de herramientas usando JSON Schema: especifica nombre, descripción y parámetros. 

Ventajas: Confiable, seguro, elimina errores de parsing.

**LangChain: Framework para Agentes Individuales RA2/IL2.1/3-langchain-agent.ipynb** 

**LangChain** actúa como una capa de abstracción que simplifica enormemente la construcción de aplicaciones con LLMs, especializándose en agentes individuales potentes. Ventajas clave: 

**Abstracciones de alto nivel** `AgentExecutor` maneja automáticament e el ciclo ReAct. 

**Ecosistema maduro** Cientos de integraciones con APIs, bases de datos y servicios. 

**Gestión automática** Historial de mensajes, formato de herramientas, manejo de errores. 

**Flexibilidad** Múltiples tipos de agentes (Zeroshot, Conversational, Structured Chat). 

**CrewAI: Orquestación de Equipos de Agentes RA2/IL2.1/4-crewai-agent.ipynb** 

**CrewAI** se especializa en equipos de agentes colaborativos. Aplicando la analogía de una agencia: no una persona que hace todo, sino especialistas que colaboran. 

**Agent** Agente individual con rol, objetivo (`goal`) e historia (`backstory`) específicos. 

**Process Task Crew** Coordinación Tarea asignada con Equipo coordinado secuencial, descripción, salida que ejecuta tareas jerárquica o esperada y siguiendo un concurrente entre dependencias. proceso definido. agentes.

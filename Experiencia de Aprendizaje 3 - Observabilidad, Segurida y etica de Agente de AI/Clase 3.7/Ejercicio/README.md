# Ejercicio Clase 3.7

## Objetivo

Construye un agente que tenga todo lo que hemos visto en clases:

- a) **LangGraph** como framework
- b) **Grafana** como observabilidad
- c) **Python** como código fuente
- d) **Streamlit** como prueba
- e) El agente puede consultar una **base de datos**, **internet** u otras fuentes como tool

Este es un ejercicio de práctica: simplemente aplica todo lo que vimos en clases.
